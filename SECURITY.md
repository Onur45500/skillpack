# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/Onur45500/skillpack/security/advisories/new) on this repository.

Include:
- A description of the issue
- Steps to reproduce
- Affected version / commit
- Any suggested fix (optional)

We aim to acknowledge reports within a few days. Once a fix is available, we will credit you (unless you prefer to remain anonymous) in the advisory and/or CHANGELOG.
